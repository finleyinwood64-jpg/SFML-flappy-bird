A Flappy Bird style game made in C++ using **SFML 3.1.0**.

Fly through the gap between the pillars for as long as you can. The game speeds up the higher your score gets.

## Controls

Key | Action 
Space | Jump 
A / D | Move left / right R | Restart after the countdown on the game over screen
F3 | Toggle hitboxes (debug) |

## How to play

1. Download the game folder
2. Make sure all the image, sound, font and .dll files are in the same folder as the .exe
3. Run Rip off flappy bird.exe
